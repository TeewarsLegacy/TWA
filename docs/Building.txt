BUILDING
------------
Small warning, now Teewars Legacy can be compiled only on linux because many of network code is oriented for linux systems.

To build Teewars Legacy you have to install g++, make, and all required dependencies listed below. 
Then run in terminal.

* ./configure
* make
* make install

Have fun :)
------------
DEPENDENCIES
------------
SDL 1.2
SDL_image 1.2
SDL_mixer 1.2
SDL_gfx 1.2
